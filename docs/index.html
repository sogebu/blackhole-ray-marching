推力
キーボードの W/A/S/D (スマホの推力は次の版。自由飛行は慣性で進む)。

自由落下の観測者は、時間が動いている間ずっと落ちる。観測者が替わるのは、パネルで選んだときと、飛ぶ・回る操作のときだけ。位置 R のスライダは今の観測者を動かし、静止の観測者は地平面の直上 R = 1.02 で止まる (内側へは自由落下で)。

画面の札の付いた「他機」 は r = 8 の円軌道を回る 1 機で、像ごとに光の遅れ・ドップラー・円盤の陰がつく (パネルの「他機」 で消せる)。
